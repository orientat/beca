# Privacitat

Aquesta arquitectura està pensada perquè les dades de l'alumnat no siguen necessàries per al funcionament del motor.

## MVP actual
- No hi ha backend.
- No hi ha base de dades.
- No hi ha enviament de dades a una API externa.
- El cas es conserva només en la memòria de la pàgina mentre està obert.

## Regla de seguretat
No introduir en una versió pública de GitHub Pages noms, DNI/NIE, adreces, informes sociopsicopedagògics, informes mèdics, dades familiars o documents de l'alumnat.

## Evolució prevista
Si més endavant es vol guardar casos, la prioritat ha de ser un sistema local i/o fitxers xifrats gestionats per l'usuari, no una base de dades pública.
