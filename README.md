# Assistent Beques NESE/NEAE 2026–2027

MVP estàtic en HTML/CSS/JavaScript per facilitar la revisió dels expedients de beques NESE/NEAE 2026–2027 als centres de la província de València.

## Principis
- Sense servidor ni base de dades.
- No introdueix noms, DNI, informes o dades personals al codi.
- El cas actual es manté en memòria del navegador.
- Motor de regles explícit i revisable.
- Quan una qüestió no està prou determinada, l'eina avisa en lloc d'inventar.
- La normativa oficial preval sobre la guia pràctica.

## Fitxers
- `index.html`: estructura i pantalles.
- `styles.css`: interfície responsive.
- `app.js`: wizard + motor de revisió.

## Publicació a GitHub Pages
1. Crea un repositori nou.
2. Puja aquests tres fitxers.
3. Activa GitHub Pages per a la branca principal i la carpeta arrel.
4. No puges expedients, informes, PDFs amb dades personals ni cap exportació amb identificadors.

## Important
Aquesta versió és un MVP funcional. Abans d'usar-la com a eina de treball definitiva cal completar i auditar totes les regles de la convocatòria, les instruccions territorials i els annexos 2026–2027.
